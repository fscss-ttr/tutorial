# 05 — Advanced FSCSS Tutorial

Logic and dynamic values.

Beginner and Intermediate gave you the whole vocabulary — variables, defines, arrays, imports. Advanced is where stylesheets start thinking: conditional branches with `@event`, data-driven output from arrays and `count()`, math and randomness, and a proper token/theme layer (`*-root`) that lets one stylesheet become many themes.
