## Ways to Contribute

### 1. Code Contributions

- Fix bugs
- Add features
- Improve performance
- Write tests

### 2. Documentation

- Fix typos
- Add examples
- Improve explanations
- Translate to other languages

### 3. Community Support

- Answer questions on Discord
- Help with issues
- Review pull requests
- Mentor new contributors

### 4. Ecosystem Development

- Create plugins
- Build tools
- Write tutorials
- Share projects

## Getting Started

### 1. Join the Community

```bash
# Join Discord
https://discord.gg/fscss

# Follow on Twitter
https://twitter.com/fscss-ttr
```

### 2. Find Issues to Work On

```bash
# Good first issues
https://github.com/fscss-ttr/FSCSS/labels/good%20first%20issue

# Help wanted
https://github.com/fscss-ttr/FSCSS/labels/help%20wanted
```

### 3. Submit Your First Pull Request

1. Fork the repository
2. Create a branch
3. Make your changes
4. Submit a pull request

## Community Guidelines

### Be Respectful

- Treat everyone with respect
- Be constructive in feedback
- Welcome newcomers

### Be Helpful

- Answer questions when you can
- Share your knowledge
- Help others learn

### Be Collaborative

- Work together on solutions
- Share ideas openly
- Give credit where it's due
