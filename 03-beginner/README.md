# 03 — Beginner FSCSS Tutorial

Core syntax only. No modules yet.

Welcome to your first hands-on section. The Introduction taught you *what* FSCSS is; here you actually write it. This section covers the four pieces of core syntax you will use every single day — variables, property multiplexing, `@define`, and choosing between the browser runtime and the CLI.

## What You'll Learn

| Lesson | Topic | Description |
|--------|-------|-------------|
| [Variables](./variables.md) | `$name` | Store and reuse values, and understand scope |
| [Property Multiplexing](./property-multiplexing.md) | `%N` | Assign one value to many properties in a line |
| [Defining Blocks](./define-basics.md) | `@define` | Build your first reusable, parameterized block |
| [Runtime vs CLI](./runtime-vs-cli.md) | Workflow | Pick the right way to run FSCSS for the task |
| [Your First Project](./first-project.md) | Practice | Build and ship a small page end to end |

## Prerequisites

- You've read the [Introduction](../01-introduction/README.md).
- FSCSS is installed (npm or CLI), or you have a browser for the CDN path.

## Goal

Write a small page stylesheet and compile (or run) it successfully.
