# 36 — Calendar Widget

A calendar is a grid pretending to be a date picker. Build the month surface from one token root, generate its weekday headings from an array, and let `num()` size the card from the same numbers the grid uses.

## The Brief

- A month card with a title, a weekday row, and a 7-column day grid.
- Weekday headings generated from one array.
- A `today` highlight plus muted and weekend day states.
- Cell size, gaps, and radius exposed as `--cal-*` tokens.

## The FSCSS

```fscss
/* palette */
@fun(color){
  surface: #ffffff;
  ink: #0f172a;
  muted: #94a3b8;
  line: #e2e8f0;
  accent: #2563eb;
  today: #eff6ff;
}

/* token root — the whole widget re-skins from three values */
@define cal-root(root: :root) {
  `
  @use(root) {
    --cal-cell: 40px;
    --cal-gap: 2px;
    --cal-radius: 8px;
  }
  `
}

@cal-root()

@define cal-shell() {
  `
  .cal {
    background: @fun.color.surface.value;
    border: 1px solid @fun.color.line.value;
    border-radius: 12px;
    padding: 1rem;
    font-family: system-ui, sans-serif;
    width: num(<7 * 40> + <6 * 2> + 32)px;
  }

  .cal-title {
    font-size: 0.95rem;
    font-weight: 700;
    color: @fun.color.ink.value;
    margin-bottom: 0.75rem;
  }

  .cal-head,
  .cal-body {
    display: grid;
    grid-template-columns: repeat(7, var(--cal-cell, 40px));
    gap: var(--cal-gap, 2px);
  }

  .cal-head { margin-bottom: 0.4rem; }

  .cal-body { grid-auto-rows: var(--cal-cell, 40px); }

  .cal-day {
    display: flex;
    align-items: center;
    justify-content: center;
    border-radius: var(--cal-radius, 8px);
    font-size: 0.85rem;
    cursor: pointer;
  }

  .cal-day:hover { background: #f1f5f9; }
  `
}

@cal-shell()

@event dayink(state) {
  if state: weekend { return: #94a3b8; }
  el-if state: muted { return: #cbd5e1; }
  el-if state: today { return: #2563eb; }
  el { return: #0f172a; }
}

.cal-day { color: @event.dayink(day); }
.cal-day--weekend { color: @event.dayink(weekend); }
.cal-day--muted { color: @event.dayink(muted); }
.cal-day--today {
  background: @fun.color.today.value;
  color: @event.dayink(today);
  font-weight: 700;
}
```

## The Data

The weekday row is the array — one entry per rule. The heading class name is built straight from the data:

```fscss
@arr(days[Mon, Tue, Wed, Thu, Fri, Sat, Sun])
@arr(di[count(@arr.days!.length, 1)])

.cal-head-@arr.days[@arr.di[]] {
  text-align: center;
  font-size: 0.7rem;
  font-weight: 600;
  text-transform: uppercase;
  letter-spacing: 0.4px;
  color: @fun.color.muted.value;
}
```

## What Happens

- `cal-root` writes the cell, gap, and radius tokens once; every rule reads them with a fallback.
- Weekday headings are generated by walking `@arr.days` — add a day to the array and a rule appears.
- `num(<7 * 40> + <6 * 2> + 32)px` computes the card width from the exact cell and gap numbers the grid uses.
- `@event dayink` maps a day state to an ink colour, so today, weekend, and muted are one lookup each.

## Stretch Goals

1. Generate 35 day-cell classes with `count(35)` so a whole month can be dropped in as data.
2. Add a `.cal--compact` modifier that halves `--cal-cell` and hides the weekday row.
3. Compute the first-cell grid offset with `num()` from a month-start index instead of leading classes.

## Summary

One token root, one weekday array, one event. The month surface is a grid; the date logic is a lookup. Swap October for any month and nothing in the stylesheet changes.
