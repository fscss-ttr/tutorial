# 21 — Image Gallery

A gallery is a grid plus a handful of decisions: how many columns, how tall the tiles are, how they respond. Build it so the column count and the gap come from a single spacing scale and the tiles are generated from data, not copy-paste.

## The Brief

- A responsive masonry-ish grid using CSS Grid.
- Tile heights and gaps driven by tokens.
- Hover lift and a caption overlay per tile.
- Column count changes at a breakpoint via a block define.

## The FSCSS

```fscss
@fun(color){
  surface: #ffffff;
  ink: #0f172a;
  scrim: rgba(15, 23, 42, 0.72);
}

@fun(space){
  gap: 0.75rem;
  pad: 1.25rem;
}

@define tile(radius: 14px) {
  position: relative;
  overflow: hidden;
  border-radius: @use(radius);
  background: @fun.color.surface.value;
  box-shadow: 0 1px 2px rgba(15, 23, 42, 0.08);
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.tile {
  @tile()
}

.tile:hover {
  transform: translateY(-4px);
  box-shadow: 0 18px 36px rgba(15, 23, 42, 0.16);
}

.tile img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.tile-caption {
  position: absolute;
  inset: auto 0 0 0;
  padding: @fun.space.pad.value;
  background: linear-gradient(to top, @fun.color.scrim.value, transparent);
  color: white;
  font-size: 0.9rem;
  font-weight: 600;
}
```

The grid itself is a block define so the breakpoint lives with the layout:

```fscss
@define gallery() {
  `
  .gallery {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: @fun.space.gap.value;
  }

  @media (min-width: 768px) {
    .gallery { grid-template-columns: repeat(4, 1fr); }
  }
  `
}

@gallery()
```

## The Data

Tile sizes are a scale, so the array drives the aspect ratios:

```fscss
@arr ratios[1, 1, 2, 1, 3, 1, 1, 2]
@arr i[count(@arr.ratios!.length, 1)]

.tile-@arr.i[] {
  grid-row: span @arr.ratios[@arr.i[]];
  aspect-ratio: 1 / 1;
}
```

## The HTML

```html
<section class="gallery">
  <figure class="tile tile-1"><img src="a.jpg" alt=""><figcaption class="tile-caption">Dunes</figcaption></figure>
  <figure class="tile tile-2"><img src="b.jpg" alt=""></figure>
  <figure class="tile tile-3"><img src="c.jpg" alt=""><figcaption class="tile-caption">Long exposure</figcaption></figure>
  <figure class="tile tile-4"><img src="d.jpg" alt=""></figure>
</section>
```

## What Happens

- `@tile()` owns the surface, radius, and transition; every tile that calls it stays in sync.
- The grid lives in a block define, so the media query travels with `columns`/`gap` instead of floating at the file bottom.
- The `tile-*` classes are generated by walking `@arr.i[]`, so adding a ninth photo means adding one code to the array — not a new rule.
- `grid-row: span` reads the aligned `@arr.ratios` value and makes some tiles taller, which is what breaks the uniform grid look.

## Compile

```bash
fscss style.fscss style.css
```

## Stretch Goals

1. Replace `span` with a real masonry via `grid-template-rows: masonry` and a `@supports` guard.
2. Add a lightbox state with `@event` keyed on `mode: open`.
3. Stagger the entrance animation with a delay array.

## Summary

Tokens for gaps and radii, a block define for the responsive grid, and an array walk for the tiles. The gallery is data plus one layout decision.
